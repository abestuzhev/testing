Тестирование React-приложений
--------------------------------

Набор примеров покрывает основные сценарии:

- Базовые unit-тесты для чистых функций
- Тестирование компонентов с Jest и React Testing Library
- Асинхронное тестирование с моками и таймерами
- Тестирование событий с fireEvent и userEvent
- Интеграционное тестирование с React Router
- Тестирование Redux с моками store и асинхронными thunks
